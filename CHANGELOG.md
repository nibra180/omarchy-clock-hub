# Changelog

All notable changes to Omarchy Clock Hub are documented here.

## [Unreleased]

### Added

- Manifest-backed Media, Agents, and System Status toggles with an in-hub quick settings menu.
- Selectable Vinyl, Equalizer, and Pulse animations for the bar's now-playing indicator, including an in-hub picker.
- Node tests for clock and calendar logic plus the Omarchy plugin contracts.

## [1.0.0] - 2026-08-26

### Added

- Theme-aware clock bar widget with configurable horizontal and vertical formats.
- Calendar hub with ISO week numbers, month navigation, year progress, and optional life progress.
- MPRIS media card with album artwork, playback controls, progress, and click-to-focus support.
- Omarchy Agents dashboard with Codex-first provider ordering, limits, daily usage, and model totals.
- Live CPU, memory, and root-disk status with a shortcut to open or focus btop.
- Minimal animated now-playing indicator using the active Omarchy accent color.
- Hyprland-derived corner rounding for the hub and album artwork.
- Automatic upstream change detection and third-party attribution.
